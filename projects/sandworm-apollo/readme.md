# Sandworm Apollo (Vertical Slice)

Scope: single playable level (Corridor → Lab → Control Room) in a small loop.
Interaction: 3 terminals (interactables) drive the entire gameplay loop.
Run length: 8–12 turns per run; each turn presents an incident + evidence and requires one action choice.
Core systems: Infection, Mutation, Power, Station Integrity, Trust in Apollo (AI advisor).
Progress: Countermeasure progress increases through sequencing/R&D actions and is required to win.
Win: reach Turn 12 with Infection below threshold AND Countermeasure progress complete.
Lose: Infection reaches 100 OR Station Integrity reaches 0 OR Power reaches 0 OR Trust collapses below threshold.
