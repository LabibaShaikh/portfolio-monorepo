## Featured engineering projects

### [1. Concurrent File Copy — C++](projects/concurrent-file-copy)

POSIX-threaded file-copying programs using a bounded producer-consumer queue, mutexes and condition variables. This was completed through pair programming with Jessica Bath; the original repository documents the shared contribution.

**Focus:** thread synchronization, shared-state safety, file I/O and defensive input validation.

### [2. Memory Allocation Simulator — C++](projects/memory-allocation-simulator)

Simulation of fixed-size allocation using linked lists, `sbrk`, first-fit and best-fit selection, deallocation and free-block coalescing.

**Focus:** memory-management policy, fragmentation, pointer arithmetic and allocator invariants.

### [3. Minecraft Maze Runner — C++](projects/minecraft-maze-runner)

Collaborative Spigot 1.19.4 integration that generates, builds and solves mazes in Minecraft. It combines recursive backtracking, wall following and a breadth-first shortest-route mode.

**Focus:** algorithm integration, external-system debugging, route visualisation and regression fixtures. The project README records LabibaShaikh's Enhancement 2, menu, debugging and testing contributions.

### [4. Soil Organics — Full-Stack Web Platform](projects/soil-organics-platform/README.portfolio.md)

Collaborative React and Node.js platform using Express, Sequelize and MySQL for products, shopping flows, authentication, reviews and administration.

**Focus:** frontend/backend integration, REST APIs, persistence and team delivery. Individual feature ownership is not overstated.

### [5. Colonoscopy Referral Triage — Machine Learning](projects/colonoscopy-referral-triage)

RMIT machine-learning capstone evaluating multiclass referral-priority prediction with Python notebooks, LightGBM, XGBoost and scikit-learn.

**Focus:** model evaluation, data validation, leakage prevention and clinical-safety review workflows. This is a university decision-support prototype, not a deployed medical product.
